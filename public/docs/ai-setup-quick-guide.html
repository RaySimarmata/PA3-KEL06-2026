🤖 Panduan Konfigurasi AI

Setup API Key untuk Fitur AI Assistant

⚠️ Masalah: AI Tidak Merespons

Jika Anda melihat pesan error ini, berarti API key belum dikonfigurasi. Pilih salah satu provider di bawah ini untuk memulai.

1. Anthropic Claude

Direkomendasikan Paid

Kualitas terbaik untuk analisis dokumen dan pembuatan laporan. Kredit gratis $5 untuk akun baru.

✨ Kualitas Terbaik 📄 Analisis Dokumen 🎯 Akurat
1 Dapatkan API Key: Buka Console Anthropic →
2 Tambahkan ke file .env:
ANTHROPIC_API_KEY=sk-ant-api03-xxxxxxxxxxxxxxxxxxxxx ANTHROPIC_MODEL=claude-3-5-sonnet-20241022
3 Restart aplikasi:
php artisan config:clear php artisan cache:clear

2. Groq

100% Gratis

Inference super cepat dengan model Llama 3.1. Gratis dengan rate limit yang cukup untuk development.

⚡ Super Cepat 🆓 Gratis 🚀 Llama 3.1
1 Dapatkan API Key: Buka Console Groq →
2 Tambahkan ke file .env:
LLM_ENABLED=true LLM_PROVIDER=groq LLM_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxxx LLM_BASE_URL=https://api.groq.com/openai/v1 LLM_MODEL=llama-3.1-8b-instant
3 Restart aplikasi:
php artisan config:clear php artisan cache:clear

3. OpenRouter

Model Gratis

Akses ke banyak model termasuk opsi gratis. Cocok untuk eksperimen dengan berbagai model AI.

🎨 Banyak Model 🆓 Ada Opsi Gratis 🔄 Fleksibel
1 Dapatkan API Key: Buka OpenRouter →
2 Tambahkan ke file .env:
OPENROUTER_API_KEY=sk-or-v1-xxxxxxxxxxxxxxxxxxxxx OPENROUTER_MODEL=meta-llama/llama-3.2-3b-instruct:free
3 Restart aplikasi:
php artisan config:clear php artisan cache:clear

💡 Tips & Troubleshooting

  • Anda hanya perlu 1 provider - Pilih salah satu yang paling sesuai
  • Rate limit exceeded? - Tunggu beberapa menit atau gunakan provider lain
  • Invalid API key? - Periksa kembali API key, pastikan tidak ada spasi
  • Masih error? - Clear cache dengan: php artisan config:clear && php artisan cache:clear
