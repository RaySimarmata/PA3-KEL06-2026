================================================================================
                        AREAS FOR IMPROVEMENT ⚠️
================================================================================

1. ⚠️ EMBEDDING QUALITY
   Current: OpenAI → Hash-based
   Needed: Add BGE-small (open source embeddings)
   Impact: Hash-based is not true semantic embedding

2. ⚠️ HARDCODED THRESHOLDS
   Current: similarity_threshold = 0.3 (30%)
   Needed: Make configurable via config/rag.php
   Impact: Low threshold might retrieve irrelevant chunks

3. ⚠️ NO CIRCUIT BREAKER
   Current: Retries immediately, no exponential backoff
   Needed: Implement circuit breaker pattern
   Impact: Could cascade-fail during provider outages

4. ⚠️ NO EMBEDDING CACHE
   Current: Same chunk re-embedded each time
   Needed: Cache embeddings by content hash
   Impact: Slow performance on repeated queries

5. ⚠️ SPARK ERROR HANDLING
   Current: Blocking HTTP call, no queue
   Needed: Use Laravel job queue
   Impact: Could timeout if Spark processing slow
