### 📌 Section 3.2.6.13: Advanced Patterns & Anti-Patterns

**Purpose:** Guide architecture decisions and prevent common mistakes

**Content:**

#### 3.2.6.13.1 Recommended Patterns ✅
- **4 design patterns** with implementation details:
  1. **Circuit Breaker** (prevent cascading failures)
     - States: Closed → Open → Half-open
     - Thresholds: 3 consecutive failures
     - Benefits: Faster failure, resource savings
  
  2. **Cache-Aside** (check cache first)
     - Steps: Check → Compute if miss → Store with TTL
     - Benefit: Fast reads, auto invalidation
  
  3. **Retry with Exponential Backoff** (intelligent retries)
     - Attempts: 1s → 2s → 4s → Fail
     - Benefit: Handle transient failures gracefully
  
  4. **Bulkhead** (resource isolation)
     - Limits: 5 Spark, 10 AI, 50 DB connections
     - Benefit: Prevent cascading failures

**Replaces:** Architecture best practices documentation

---

#### 3.2.6.13.2 Anti-Patterns to Avoid ❌
- **5 common mistakes** with explanations:
  1. **Blocking HTTP for Long Jobs** ❌
     - Problem: Timeout after 30 sec
     - Solution: ✅ Queue job, return immediately
  
  2. **Hardcoded Thresholds** ❌
     - Problem: Can't tune without redeploying
     - Solution: ✅ Move to config, allow dynamic adjustment
  
  3. **No Error Handling** ❌
     - Problem: Unhandled exceptions crash
     - Solution: ✅ Try-catch all external calls
  
  4. **Unnecessary Re-embedding** ❌
     - Problem: Wasted API calls
     - Solution: ✅ Cache embeddings by hash
  
  5. **Single Provider Dependency** ❌
     - Problem: Service outage = system outage
     - Solution: ✅ Implement 5+ provider fallback chain

**Replaces:** Anti-patterns guidance in architecture documentation

### 📌 Section 3.2.6.14: Debugging & Troubleshooting Guide

**Purpose:** Help operational team resolve common issues

**Content:**

#### 3.2.6.14.1 Common Issues & Solutions
- **4 troubleshooting scenarios:**
  
  1. **Issue: Laporan Generation Hangs (> 30 sec)**
     - Likely causes: RAG slow, AI timeout, DB issue
     - Debug steps: Check logs, monitor query time
     - Solutions: Add index, increase timeout, upgrade CPU
  
  2. **Issue: Quality Score Always Low (< 0.7)**
     - Likely causes: Irrelevant RAG, vague prompt
     - Debug steps: Check chunk similarity, prompt clarity
     - Solutions: Improve chunking, refine template, add training data
  
  3. **Issue: File Upload Fails**
     - Likely causes: File too large, wrong type, permission denied
     - Debug steps: Check error message, file size/type, permissions
     - Solutions: Increase limit, add type to whitelist, fix permissions
  
  4. **Issue: Cache Not Invalidating**
     - Likely causes: Cache key not cleared, TTL too high, wrong layer
     - Debug steps: Check cache keys, TTL values, trigger code
     - Solutions: Call Cache::forget(), reduce TTL, use tags
